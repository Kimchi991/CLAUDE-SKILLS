# Angle Library

Never default to one arc. Diagnose the product, then pick the angle that makes its core benefit most
visceral. Often you fuse two. State the chosen angle + progression spine in one sentence with a
one-line rationale.

## The four mechanics every ad hits

- **A. Curiosity-gap hook** — a question the viewer needs answered (see `hook-library.md`).
- **B. Escalating spine** — a ladder that intensifies: Time (Day 1 → 30 → 365) · Quantity (1 → 42) ·
  Stage/Level (Stage 1 → 5).
- **C. Visceral concrete specifics** — each beat is one physical, sensory image, not an abstract claim.
- **D. A payoff** — triumph (transformed, crowned) or catastrophe (system failure, ruin).

## Choosing the angle

| Diagnose the product… | Angle | Spine | Payoff |
|---|---|---|---|
| Benefit compounds over time? | **Transformation** ("use it for 30 days") | Time | Triumph |
| Painful worsening status quo? | **Cost-of-inaction** ("what if you never fix this") | Time | Catastrophe |
| People overdoing a broken old way? | **Limit / overload** ("how far before it breaks") | Quantity | Catastrophe |
| Vivid in an unexpected world/era? | **Origin / scenario** ("what if you had this in [world]") | Time/Stage | Triumph |
| Clear rival to beat? | **Comparison** ("the old way vs this") | Stage | Triumph |
| The problem is the villain? | **Personify-the-problem** (the problem as a character/monster) | Stage | Triumph |
| Relatable daily pain? | **POV / day-in-the-life** (first-person through the problem) | Time | Triumph |

## Translate every benefit into a visible image (the craft)

| Abstract benefit | Visceral image |
|---|---|
| Saves time | "You blink and the work's already done. You stare at an empty to-do list, twitching." |
| Reduces churn | "Customers used to vanish like smoke. Now they're chained to you, grinning." |
| More leads | "Day 30: the leads stop trickling. They kick down the door." |
| Cuts cost | "Your burn rate was a bonfire. Now it's a birthday candle." |
| Fixes a health/body problem | show it *inside the body* (pair with the x-ray style) |

Banned corporate words: revolutionary, seamless, leverage, solution, game-changer (unless ironic).
Say what physically happens.
