# Storyboard

Draft the whole visual plan fast and cheap, then split it into strategic anchors. Do not generate one
polished still per line from scratch.

## Grid-first

- After SCRIPT LOCK and VOICE, draft the entire board in one pass (a GPT/LLM storyboard grid is ideal:
  one image, all panels, with a hero-character note). This is a Version-1 blueprint, not the final ad.
- The human edits the board: cut weak panels, merge duplicates, fix beats.

## Split into STRATEGIC ANCHORS (not one per line)

A 26-line script does not need 26 anchors. Merge:

- Near-identical detail shots (four "starving follicle" panels → one).
- Micro-beats that share a setting and action.
- Redundant "science visual" filler.

Aim for a compact set of **meaningful visual states** (often ~8 to 14 for a 60s ad). Each anchor:

- Is a distinct composition, not a near-duplicate of its neighbor.
- Maps to a span of voiceover lines and a slice of the timeline.
- Earns its place: state the anchor count and reason before generating.

Fast visual variety happens *inside* each clip through motion (see `motion-grammar.md`), not by adding
more anchors.

## Map to the voiceover timeline

For each anchor record: time range · voiceover lines · the beat's action · camera concept · product
presence · which clip(s) it drives. Long anchor blocks (over the model's max clip length) split into
two clips from the same anchor.

## Per-scene fields (Version-1 board)

For each beat: voiceover line · situation · setting · character state · emotion · product presence ·
props · action · camera concept · suggested on-screen text (editor only) · approximate timing ·
image requirement · video requirement.
