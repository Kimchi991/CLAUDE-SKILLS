# Roblox Story Mode

A separate mode from Ad mode. Use it for viral Roblox **story** content (YouTube Shorts/TikTok/Reels),
NOT product ads. The difference that matters: in stories **characters speak** (dialogue, no narrator);
in ads **nobody speaks** (VO carries). Never mix the two rule sets.

Use the shared `styles/roblox.md` visual pack, but this mode has its own structure below.

## Story modes
1. Rich vs Poor · 2. Funny · 3. Family · 4. Mystery · 5. Cartoon Adventure

## Output rule
Begin immediately with the Video Title and Scene 1. No intro, notes, or setup text. Generate the story
directly. Family-friendly, kid-safe, advertiser-friendly, original.

## Visual style lock
Roblox-style 3D animation, bright colorful world, soft cinematic lighting, soft shadows, high-quality
render, cartoon Roblox avatars only. Forbidden: realistic humans, celebrity likeness, live action,
graphic content. (IP: never reproduce a real Roblox game or named character — see `CONSTITUTION.md`.)

## Character consistency
Repeat the FULL appearance description inside every scene prompt. Never write "same character",
"same outfit", "same boy/girl" — always rewrite the whole description so each scene stands alone.
Keep identical: hair style/color, eye color, face style, clothing colors, shoes, accessories, body
proportions, avatar appearance. (Same principle as `modules/consistency.md`.)

## World consistency
The whole story stays inside one Roblox world: consistent environment style, lighting, atmosphere,
palette, camera and render quality. It should feel like one continuous movie.

## Scene rules
6 to 8 scenes, 7 seconds each, every scene continuing naturally from the last. For each scene:
scene number · duration · detailed AI video prompt · camera angle · camera movement · character
actions · facial expressions · environment · visual effects · emotional context · continuity.

## Dialogue rules
Only characters may speak: simple American English, short sentences, natural conversation. No narrator,
no voiceover.

## Retention
Curiosity gaps, emotional moments, unexpected twists, retention hooks, visual contrast, surprise
events, satisfying ending. Binge-worthy and clickable.

## Optional post-story assets
Thumbnail text · thumbnail concept · description · SEO keywords · hashtags · pinned comment. (Omit for
ad work — ads do not need these.)

## NEXT command
End with: "Type NEXT for a completely new story." On NEXT: new title, characters, world, challenge,
twist, ending — never repeat previous ideas.
