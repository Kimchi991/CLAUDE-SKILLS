# CLAUDE-SKILLS

## Animation OS

A flexible AI ad-production skill: turn any product, offer, or script into a short-form animated
advertisement in any viral animation style (skeleton, x-ray skeleton, dressed skeleton, Roblox, anime,
and more). One repeatable pipeline, swappable Style Packs.

```
animation-os/
├── SKILL.md              main router — the pipeline, mode routing, and non-negotiables
├── CONSTITUTION.md       safety + platform-risk + brand-safe filter (always in force)
├── ARCHITECTURE.md       business context, format-agnostic design, roadmap
├── roblox-story.md       Story mode (viral Roblox stories — characters speak)
├── styles/               swappable Style Packs (one per animation style, + _TEMPLATE)
└── modules/              creative libraries + rules (angle, hook, motion, storyboard,
                          consistency, product-truth-lock)
```

Start at `animation-os/SKILL.md`.
